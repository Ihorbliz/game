# Міньйон і Руда Білка

Весела гра-платформер для телефона (у горизонтальному положенні) і комп'ютера.
Жовтий Міньйон біжить крізь 40 світів, збирає банани і стрибає на ворогів,
а за ним усюди бігає його вірна подружка — Руда Білка.

Уся графіка намальована кодом, а звуки створюються прямо в браузері.
Жодних зовнішніх файлів, картинок чи інтернету грі не потрібно.

## Як грати

- Збирай банани 🍌 — за них наприкінці рівня дають зірки (до трьох).
- Стрибай ворогам на голову, щоб їх перемогти.
- Прапорці на рівні — це контрольні точки: якщо щось піде не так, гра продовжиться звідти.
- У Міньйона 3 сердечка. Торкнувся ворога збоку — мінус одне сердечко.
- Дійди до кінця рівня, щоб відкрити наступний.

Нові перешкоди з 16-го рівня:
- **шипи** — їх треба перестрибувати;
- **тріснуті плити** — обвалюються, якщо на них постояти, тож біжи далі;
- **ліфти** — платформи, що їздять угору-вниз до високих уступів;
- **вороги-стрибунці** — підскакують на місці.

## Керування

**Телефон (тримай горизонтально):**
- ліва половина екрана — кнопки ◀ ▶ (бігти вліво / вправо);
- права половина екрана — стрибок.

**Комп'ютер:**
- ← → або A / D — бігти;
- Пробіл або ↑ — стрибок;
- P або Esc — пауза.

## Як грати на телефоні без інтернету

Гру треба один раз викласти в інтернет — наприклад, на Netlify (безкоштовно, репозиторій може бути приватним):

1. На app.netlify.com увійди через GitHub → **Add new project → Import an existing project → GitHub**.
2. Дай доступ до репозиторію з грою, вибери гілку `main`, команду збірки залиш порожньою → **Deploy**.
   (Або GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root; на безкоштовному тарифі
   для цього репозиторій має бути публічним.)
3. З'явиться посилання на гру. Netlify сам оновлює сайт після кожної зміни в `main`.
4. Відкрий це посилання **один раз** на телефоні з інтернетом
   (у Chrome на Android або Safari на iPhone) і дочекайся, поки гра завантажиться.
5. Додай гру на головний екран:
   - **Chrome (Android):** меню ⋮ → «Додати на головний екран» (або «Установити застосунок»);
   - **Safari (iPhone):** кнопка «Поділитися» → «Додати на головний екран» («На початковий екран»).
6. Готово! Тепер гра запускається з іконки на головному екрані і працює **без інтернету**.

**Як отримати оновлення гри:** коли телефон в інтернеті, відкрий гру з іконки й почекай кілька секунд
у меню, потім закрий її і відкрий знову — з'явиться нова версія. Прогрес (відкриті рівні й зірочки) зберігається.

## Як грати на комп'ютері

Можна просто відкрити файл `index.html` у браузері (подвійним кліком) — гра запуститься і без сервера,
і без інтернету.

## Порада для батьків

У головному меню **торкніться назви гри 5 разів поспіль** — відкриються всі рівні.
